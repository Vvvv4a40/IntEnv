# Проект Envi

- Пользователь разрешил публикацию и дальнейшие коммиты в `https://github.com/Vvvv4a40/IntEnv` (`origin`, основная ветка `main`). После завершения согласованной задачи проверь изменения, создай осмысленный коммит и отправь обычным push. Не переписывай чужую историю; для новых отдельных веток используй префикс `codex/`. Не считай разрешение коммитить разрешением реализовывать новые несогласованные возможности.

- Для вопросов об архитектуре и запуске сначала прочитай `README.md` и `docs/architecture.md`. Если доступны локальные `context.md` и `concept.md`, учитывай историю решений; они содержат личные заметки, исключены из Git и не должны публиковаться. В чистом клоне их отсутствие нормально.
- Различай подтверждённые решения пользователя, предложения ассистента и инженерные выборы реализации. Для v0.1 согласованы Groq API и основной процесс Windows; Ubuntu/WSL остаётся для Linux-практики. По явному запросу «Оукей, перенеси код на пайтон и также опиши структуру» 4 октября основное приложение перенесено на Python. Tkinter, WinMM через ctypes и HTTP стандартной библиотеки — инженерные выборы реализации. Прежняя C#/.NET 10/WPF база сохранена в `legacy/csharp`, не используется и не удалена. Playwright, Pipecat, классификатор, TTS и iPhone пока не подключены.
- Когда пользователь явно меняет решение, обнови `context.md`; при изменении архитектуры также обнови `concept.md`. Не устанавливай ПО и не начинай реализацию только на основании обсуждения теории.
- Схема текущих файлов — `docs/architecture.md`, запуск и данные/лимиты — `README.md`. Проверка: `./verify.ps1`; тесты используют fake-модель/HTTP/инструменты, не должны запускать приложения, записывать микрофон или расходовать API-квоту.
- Не добавляй произвольный shell-tool. Новые действия должны иметь ограниченную схему, валидацию и политику подтверждения. Не сохраняй API-ключ, аудио или тексты диалога в журнал.
- Будущий классификатор точно обучается на Python по выбору пользователя. Единое Python-ядро уже реализовано; обучение остаётся отдельным будущим процессом, применение модели подключается через `Router`. ML-библиотека, алгоритм и среда обучения Windows/WSL не выбраны. Не выдавай обучение на Python за техническую невозможность исполнения модели на другом языке. Не удаляй резервную C#-базу без отдельного запроса.
