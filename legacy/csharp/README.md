# Envi — база v0.1

Нативный помощник Windows: текстовый ввод, запись речи кнопкой, ответы через Groq и несколько разрешённых действий на ПК. Основной процесс работает в Windows; Ubuntu/WSL для запуска не нужна и остаётся отдельной средой для изучения Linux.

Основа написана на **C# / .NET 10 / WPF**. Это технический выбор для начальной реализации: нужный SDK уже установлен на этом компьютере. Сторонних NuGet-пакетов, локальной LLM и Python-зависимостей пока нет.

## Запуск

Из PowerShell в папке проекта:

```powershell
.\start.ps1
```

Без API-ключа можно проверить текстовые команды:

- `Который час?`
- `Открой папку проекта`
- `Открой блокнот`
- `Открой калькулятор`
- `Открой VS Code`

Открытие приложений и папки потребует подтверждения с показом точного пути. Эти команды — начальный набор реализации, а не ограничение будущего помощника. Пути приложений настроены для текущего компьютера.

Для речи и остальных вопросов нужен свой ключ из [кабинета Groq](https://console.groq.com/keys). Введи его скрыто в том же терминале, затем запусти приложение:

```powershell
$env:GROQ_API_KEY = [System.Net.NetworkCredential]::new('', (Read-Host 'Ключ Groq' -AsSecureString)).Password
.\start.ps1
```

Ключ находится только в окружении терминала и дочернего приложения: скрипт не сохраняет его в файл. Не присылай ключ в чат и не добавляй его в JSON или Git. Чтобы убрать его из терминала после закрытия Envi: `Remove-Item Env:GROQ_API_KEY`.

Если PowerShell запрещает запуск `.ps1`, не меняй глобальную политику ради Envi. Можно выполнить напрямую:

```powershell
dotnet restore .\src\Envi.Desktop\Envi.Desktop.csproj --configfile .\NuGet.Config
dotnet run --no-restore --project .\src\Envi.Desktop\Envi.Desktop.csproj -- --settings "$PWD\envi.settings.json"
```

## Как пользоваться

Напечатай запрос и нажми «Отправить» или Ctrl+Enter. Для голоса нажми «Записать речь», произнеси фразу, нажми кнопку снова. Через 30 секунд запись остановится автоматически. Аудио отправляется в Groq; распознанный текст появляется в поле ввода, **не выполняется автоматически**. Проверь его и отправь.

«Отмена» прекращает запись/ожидание запроса; уже запущенное приложение не закрывает. «Очистить окно» очищает диалог и память модели в этой сессии, но не удаляет журнал на диске. Ключ читается при запуске — после смены окружения Envi нужно перезапустить.

## Настройки, стоимость и данные

[envi.settings.json](envi.settings.json) содержит модели, таймауты, лимиты и разрешённые приложения/папки. Изменения применяются после перезапуска. Относительные пути папок считаются от каталога этого файла, поэтому для папки проекта пользуйся `start.ps1`, а не запуском скопированной сборки без `--settings`.

Начальные модели: `openai/gpt-oss-20b` для текста, `whisper-large-v3-turbo` для речи. Их названия и HTTP-формат сверены с [документацией Groq](https://console.groq.com/docs/models) и [STT](https://console.groq.com/docs/speech-to-text) 4 октября 2026 года. Доступность и бесплатные квоты в твоём аккаунте нужно проверить отдельно.

По умолчанию: 100 API-запросов на запуск приложения, максимум 3 раунда инструментов на запрос, до 600 выходных токенов за вызов модели, 12 сообщений истории (6 пар). Счётчик общий для STT и чата, включая неудачные отправки. Запрос с инструментами может вызвать модель несколько раз. Это **ограничитель числа запросов, не денежный бюджет**; перезапуск сбрасывает счётчик. Автоповторов после ошибки нет. Для реальных расходов используй ограничения аккаунта Groq.

В облако уходят записанная речь и, при запросе модели, текущий текст, последние сообщения диалога, схемы инструментов и результаты их вызова. В том числе предыдущие локальные команды могут позже попасть в историю облачного запроса. Полные пути разрешённых приложений в схемы не включены. Envi не отправляет экран, содержимое файлов или аудио в фоне.

Аудио и диалог находятся в памяти, не сохраняются приложением на диск. Журнал `%LOCALAPPDATA%\Envi\events.jsonl` содержит только технические события: маршрут, число инструментов, результат проверки/подтверждения, факт выполнения. Тексты запросов, аудио и ключ не журналируются. Политика обработки данных самим облачным сервисом — отдельный вопрос.

## Файлы и проверки

Схема файлов и путь запроса: [docs/architecture.md](docs/architecture.md). История решений: [context.md](context.md). Концепция и дальнейшие этапы: [concept.md](concept.md).

Проверить сборку, автономные тесты и инициализацию окна:

```powershell
.\verify.ps1
```

Тесты используют подставные ответы модели/HTTP и не открывают программы, не записывают микрофон и не тратят API-квоту. Проверка `--smoke-test` создаёт интерфейс без показа окна и завершается. Реальный звук, ответы Groq и открытие приложений требуют отдельной ручной проверки.

## Что пока не входит

Нет озвучивания, слова активации, обученного классификатора, браузерного поиска, управления элементами окон, исполнения PowerShell/Python-кода от модели, iPhone и интеграции Codex. Обычный ответ модели не является исследованием с проверенными актуальными источниками. Эти возможности добавляем отдельными инструментами и адаптерами после проверки базового цикла.
