# Резервная копия C#-версии

`csharp/` содержит прежние исходники, .NET-тесты, настройки, скрипты и документацию Envi v0.1 до переноса на Python. Код **перемещён, не удалён**. Это архив для восстановления/сравнения, не часть запуска Python-приложения.

Основной проект теперь находится в `envi/` и использует корневые `start.ps1`, `verify.ps1` и `envi.settings.json`. .NET для него не нужен.

Архивные пути и документация описывают состояние до миграции. При запуске старого `csharp/start.ps1` его папка `project` указывает на `legacy/csharp`, потому что относительные папки разрешаются от файла настроек; не путать с корнем актуального проекта. Не редактируй обе версии параллельно без отдельного решения.
