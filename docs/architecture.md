# Архитектура Python-файлов Envi v0.1

Один процесс Windows, два слоя: окно и независимое ядро. Весь активный код — Python. Groq выполняет удалённые STT/LLM; локальная нейросеть пока не запускается. C#/.NET не являются зависимостями и сохранены только в архиве.

## Дерево проекта

```text
Envi/
├─ README.md                    Запуск, ограничения, ключ и данные
├─ start.ps1                    Запуск Python из корня проекта
├─ verify.ps1                   Синтаксис + unittest + скрытый запуск окна
├─ pyproject.toml               Метаданные Python-пакета, без runtime-пакетов
├─ envi.settings.json           Модели, лимиты, разрешённые приложения/папки
├─ context.md                   Личная история, только локально
├─ concept.md                   Личные планы, только локально
├─ AGENTS.md                    Правила работы с проектом
├─ docs/architecture.md         Эта схема
├─ research/                    Личные заметки, только локально
├─ envi/                        Основной Python-пакет
│  ├─ __init__.py               Объявление пакета и версия
│  ├─ __main__.py               Точка входа: python -m envi
│  ├─ ui.py                     Окно Tkinter, кнопки, подтверждения
│  ├─ audio.py                  Микрофон WinMM → WAV в памяти
│  ├─ assistant.py              Управляющий цикл и история
│  ├─ models.py                 Форматы сообщений + интерфейсы модулей
│  ├─ routing.py                Точные локальные правила
│  ├─ tools.py                  Проверки и запуск разрешённых действий
│  ├─ configuration.py          Чтение и проверка настроек
│  ├─ cancellation.py           Общая отмена операции
│  ├─ errors.py                 Безопасные сообщения об ошибках
│  ├─ json_utils.py             Строгий JSON без повторных полей/NaN
│  ├─ event_log.py              Технический журнал без секретов
│  └─ providers/
│     ├─ __init__.py
│     └─ groq.py                REST-клиент STT/LLM + HTTPS-транспорт
├─ tests/                       unittest и подставные зависимости
│  ├─ helpers.py                Fake-модель, HTTP и инструменты
│  ├─ test_assistant.py         Цикл, подтверждения, отмена, история
│  ├─ test_groq.py              JSON/multipart, квоты, ошибки
│  ├─ test_transport.py         HTTP-отмена/дедлайн без сети
│  ├─ test_router_tools.py      Правила, аргументы, разрешённые цели
│  ├─ test_configuration_log.py Настройки, журнал, отмена
│  └─ test_desktop.py           Скрытый Tk и подставной WinMM
└─ legacy/
   ├─ README.md                 О резервной копии
   └─ csharp/                   Прежний .NET-код, тесты и документы
```

.py — код, __init__.py — пакет, __main__.py — запуск через python -m. Папка __pycache__ появляется автоматически: её не редактируем и не сохраняем в Git. pyproject.toml не запускает установку зависимостей; для работы из исходной папки установка самого пакета не нужна.

## Путь запроса

```text
ui.py — текст с клавиатуры
  │
  ├─ голос: audio.py → GroqClient.transcribe → поле ввода
  │                                          │
  │                          человек проверяет и отправляет
  ▼
assistant.py
  ▼
routing.py
  ├─ точная известная фраза ─────────────────────┐
  └─ остальное → GroqClient.complete            │
                      ├─ обычный ответ → окно  │
                      └─ вызовы инструментов ──┤
                                              ▼
                                     tools.py: валидация
                                              ▼
                                     подтверждение в ui.py
                                   (кроме чтения времени)
                                              ▼
                                     tools.py: исполнение
                                       ├─ правило → ответ в окно
                                       └─ модель → результат в Groq
                                                    → ответ в окно
```

Groq возвращает предложение, не исполняемый Python-код. Любой маршрут проходит ту же границу проверок. События отправляются в event_log.py; он не является памятью диалога или датасетом.

## Обязанности модулей

**__main__.py соединяет детали.** Загружает настройки, берёт ключ из окружения, создаёт клиент, правила, инструменты, журнал и AssistantService, запускает окно. Есть doctor, скрытый smoke-test и одиночный текстовый режим. Не обучает модель и не ставит пакеты.

**ui.py общается с человеком.** Показывает ввод, диалог, состояние и счётчик API. Запись сначала становится проверяемым текстом. Сеть/ядро идут в worker-потоке; подтверждения и результаты — через Queue, которую читает Tk-поток через after. Только основной поток трогает окно. По умолчанию подтверждение отказывает. Закрытие/отмена освобождают ожидающие подтверждения без зависания на сети.

**audio.py только записывает.** Windows WinMM через ctypes: 16 kHz, 16 бит, mono PCM, до 30 секунд. Драйвер сигналит событием, не Python-callback. Открытие и освобождение устройства — в отдельном потоке. WAV остаётся в памяти; при отмене отбрасывается. Если драйвер не отпустил буфер, код не освобождает память, на которую он ещё может ссылаться.

**assistant.py — диспетчер.** Один запрос за раз; локальный путь или Groq, история, цикл tool calling. Весь набор предложений проверяется и подтверждается до первого запуска. Повторные ID/действия, лишние вызовы и обрезанные ответы отклоняются. Если сбой/отмена произошли после действия, итог сообщает о выполненной части; запуск не откатывается. В памяти только полные пары «пользователь / итог», не оборванные tool-сообщения.

**routing.py выбирает дешёвый путь.** Правила, не обученный классификатор. Совпадает вся фраза про время/папку/известное приложение. Отрицания, вопросы о команде и составные задания не становятся локальным действием автоматически. Голосовое STT уже использовало облако, даже если команда локальна.

**tools.py — граница полномочий.** Только get_time, open_app(app), open_folder(folder). Имена целей из JSON-allowlist, не произвольные пути модели. Проверяются формат, поля, типы, aliases и существование цели; смена разрешённого пути требует перезапуска. Повторная проверка перед исполнением. Фиксированные аргументы Popen(..., shell=False), командные оболочки запрещены, API-ключ не передаётся дочерней программе. Настройки — доверенный файл, не песочница для неизвестных EXE.

**providers/groq.py изолирует облако.** Два фиксированных HTTPS endpoint Groq, без перенаправлений/автоповторов. Чат сериализует сообщения и схемы, STT — проверенный WAV как multipart. Общая квота, предел ответа, таймаут, безопасные ошибки. Отмена закрывает сокет; неявное повторное соединение запрещено. Системное DNS-разрешение не всегда можно сразу прервать — поздний ответ не продолжает действия.

**configuration.py, cancellation.py, event_log.py** — доверенные настройки, отмена и технические метаданные. Ключ не в JSON; аудио и тексты в журнал не входят.

## Где будет классификатор

В models.py есть интерфейс `Router.try_route(text) → ToolCall | None`. Пока подключён RuleRouter. Будущий Python-адаптер применяет обученную модель и возвращает проверяемое предложение либо None («не знаю»), не исполняет действие.

Обучение отделяем от помощника:

- будущий training/: явно собранные/размеченные фразы, обучение и оценка;
- будущий адаптер Router: загрузка готовой модели, обработка текста, порог/отказ;
- tools.py: те же разрешения, аргументы и подтверждения независимо от score.

ML-файлы ещё не созданы, пакеты не выбраны, модель не обучена. Не превращать журнал без текста в скрытый сбор фраз. Классификация open_app отдельно от проверки аргумента vscode; низкая уверенность/неподдержанный запрос → Groq или уточнение.

## Расширение

| Изменение | Место |
| --- | --- |
| Модель Groq, лимит, ещё одна папка/программа | envi.settings.json + перезапуск |
| Ещё одна точная фраза | routing.py + тесты |
| Обученный классификатор | Новый адаптер Router, обучение отдельно |
| Новый тип действия | Обработчик/схема/проверки в tools.py или отдельном модуле + тесты |
| Другой провайдер | Новый ModelClient в providers/, соединение в __main__.py |
| Playwright/Python-сценарий | Ограниченный инструмент, не свободный код модели |
| TTS/слово активации | Отдельный голосовой модуль |
| iPhone/WSL-backend | Отдельный защищённый клиент/транспорт после согласования |

Ни framework, ни второй язык сейчас не требуются. Обычные Python-объекты; Protocol фиксирует методы и позволяет заменять зависимости fake-объектами.

## Проверка и границы

verify.ps1 проверяет синтаксис, unittest и окно без показа. Подставные HTTP/WinMM/процессы проверяют контракты и безопасность, не акустику, качество модели, квоту аккаунта или загрузку окна запускаемой программы. «Запуск запрошен» означает передачу команды Windows, не доказательство полной готовности приложения.

Источники: [Groq API Reference](https://console.groq.com/docs/api-reference), [STT](https://console.groq.com/docs/speech-to-text), [tool calling](https://console.groq.com/docs/tool-use/local-tool-calling), [Tkinter](https://docs.python.org/3/library/tkinter.html).
