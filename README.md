# Envi — Python-база v0.1

Репозиторий: [Vvvv4a40/IntEnv](https://github.com/Vvvv4a40/IntEnv).

Персональный помощник Windows: текстовый ввод, запись речи кнопкой, ответы через Groq и разрешённые действия на ПК. Основное приложение целиком на Python — без C#/.NET и без обязательного сервиса в WSL. Ubuntu остаётся для Linux-практики и возможного будущего обучения классификатора.

Для базы нужны Python 3.11+ и Tkinter. Внешних Python-пакетов пока нет: окно — tkinter/ttk, запись — Windows WinMM через ctypes, HTTP — стандартная библиотека. На текущем компьютере проверены Python 3.12.12 из MSYS2 и Tk 8.6.17: отсутствие pip не мешает этой версии. Для будущих ML-библиотек и Playwright лучше отдельно подготовить обычный Windows CPython с виртуальным окружением; сейчас ничего не устанавливалось.

## Запуск

Из PowerShell в папке проекта:

```powershell
.\start.ps1
```

Скрипт предпочитает `.venv\Scripts\python.exe`, если такая среда есть; иначе берёт python из PATH. Интерпретатор можно указать явно: `.\start.ps1 -Python 'C:\путь\python.exe'`. Виртуальное окружение автоматически не создаётся.

Без скрипта, если политика PowerShell запрещает .ps1:

```powershell
python -X utf8 -m envi
```

Без ключа работают локальные текстовые команды:

- `Который час?`
- `Открой папку проекта`
- `Открой блокнот`
- `Открой калькулятор`
- `Открой VS Code`

Открытие приложения/папки требует подтверждения точного пути. Это начальный набор, не предел будущего помощника. Пути настроены для текущего компьютера в [envi.settings.json](envi.settings.json).

## Подключение Groq

Речь и остальные вопросы используют свой ключ из [кабинета Groq](https://console.groq.com/keys). В том же терминале введи ключ скрыто и запусти Envi:

```powershell
$env:GROQ_API_KEY = [System.Net.NetworkCredential]::new('', (Read-Host 'Ключ Groq' -AsSecureString)).Password
.\start.ps1
```

Ключ остаётся в окружении текущего терминала и Envi, но не сохраняется в файл/историю команды. Не присылай ключ в чат и не добавляй в JSON или Git. Envi убирает ключ из окружения запускаемых им программ. После закрытия Envi можно убрать его из терминала: `Remove-Item Env:GROQ_API_KEY`.

Начальные модели: openai/gpt-oss-20b для текста и whisper-large-v3-turbo для речи. Названия и REST-формат сверены с официальными [моделями Groq](https://console.groq.com/docs/models) и [API Reference](https://console.groq.com/docs/api-reference). Доступность, бесплатную квоту и ограничения расходов проверь в своём аккаунте. Groq SDK сейчас не установлен: адаптер напрямую вызывает тот же REST API, его можно заменить отдельно.

## Работа с окном

Напечатай запрос и нажми «Отправить» или Ctrl+Enter. Для голоса нажми «Записать речь», произнеси фразу и нажми кнопку снова. Максимум 30 секунд, затем автоостановка. Запись отправляется в Groq STT, текст появляется в поле ввода. Команда не отправляется и не выполняется автоматически: проверь распознавание и нажми «Отправить».

«Отмена» прекращает обработку; уже запрошенный запуск приложения не откатывает. Если действие успело выполниться до отмены или сбоя, итог перечисляет его. «Очистить окно» очищает диалог и память модели этой сессии, не удаляя журнал на диске. Ключ и настройки читаются при запуске, после изменения перезапусти Envi.

Сеть, управляющий цикл и аудиодрайвер работают в фоновых потоках. Только основной поток изменяет окно; подтверждения передаются ему через очередь. Закрытие отменяет ожидающие операции без блокирующего ожидания сети/драйвера. Отмена сети не гарантированно мгновенна во время системного DNS-разрешения/соединения, но поздний ответ не инициирует новые действия.

## Настройки, лимиты и данные

Модели, пути и лимиты — в envi.settings.json; ключ туда не входит. Используются Python-имена chat_model, apps и т. п. Старые CamelCase-поля тоже читаются, но неизвестные/повторные поля отклоняются. Относительные папки разрешаются от каталога файла настроек. По умолчанию берутся настройки из корня исходного проекта, а не случайной текущей папки.

Начальные ограничения:

- 100 отправок STT/чата на запуск приложения, включая неудачные;
- максимум 3 раунда инструментов на запрос, до 5 вызовов в наборе;
- до 600 выходных токенов за вызов модели и 12 сообщений истории (6 пар);
- запись до 30 секунд, ожидание API — до 30 секунд с оговоркой о системном DNS.

Общий счётчик — не денежный бюджет. Один вопрос с инструментами может потребовать нескольких запросов модели; перезапуск сбрасывает локальную квоту. Автоматических повторов после ошибки нет. Настоящие ограничения расходов устанавливаются у провайдера.

В Groq уходят запись голоса и, при запросе модели, текущий текст, последние сообщения диалога, схемы инструментов и результаты их вызова. Предыдущие локальные команды тоже могут попасть в последующую историю модели. Схемы раскрывают разрешённые имена, не полные пути. Экран, содержимое файлов и фоновый звук не отправляются.

Аудио и диалог остаются в памяти и не сохраняются Envi на диск. Журнал `%LOCALAPPDATA%\Envi\events.jsonl` содержит только технические события без текста запросов/ответов, аудио и ключа. Политика обработки самим Groq — отдельный вопрос.

## Проверки

```powershell
.\verify.ps1
```

Без скрипта:

```powershell
python -X utf8 -m unittest discover -s tests -v
python -X utf8 -m envi --smoke-test
python -X utf8 -m envi --doctor
```

Тесты используют подставные модель, HTTP, WinMM и запуск процессов. Они не открывают приложения, не записывают микрофон и не тратят API-квоту. Smoke-test создаёт окно без показа и сразу завершается. Doctor показывает среду и наличие ключа, не его значение. Недоступные Tk/Windows-symlink проверки явно пропускаются.

Последний прогон на этом компьютере: 82 теста, 81 прошёл, 1 пропущен из-за отсутствия прав на создание symlink; синтаксис и скрытая инициализация окна успешны.

Необязательный текстовый режим: `python -X utf8 -m envi --text 'Который час?'`. Он исполняет локальные команды или реально обращается к Groq для прочих запросов, если задан ключ; запуск действий подтверждается в терминале.

Для другой установки предпочтителен официальный Python с Tcl/Tk. Установка пакета/сборка отдельного .exe пока не проверены; основной способ — запуск из исходной папки. Реальные звук, Groq и открытие программ требуют ручной проверки.

## Структура и следующий этап

[docs/architecture.md](docs/architecture.md) — схема файлов, границы компонентов и место будущего классификатора. Личные `context.md`, `concept.md` и исследовательские заметки сохранены только локально и не входят в публичный репозиторий. Клонированному проекту они для запуска не нужны.

Прежняя C#-база перемещена, не удалена, в legacy/csharp. Она не используется Python-приложением; [legacy/README.md](legacy/README.md) объясняет резервную копию.

Классификатор пока не обучен и не подключён: предусмотрен интерфейс Router, сейчас его реализуют правила. Будущее обучение — отдельный Python-процесс, применение модели — внутри Envi. Нет TTS, слова активации, браузерного поиска, произвольного исполнения shell/Python-кода от модели, iPhone или Codex. Обычный ответ модели не является исследованием с проверенными свежими источниками.

## Работа с Git

Основная ветка — `main`, удалённый репозиторий — `origin`. После согласованного изменения: автономные проверки, просмотр diff, отдельный осмысленный коммит и обычный push. Не использовать force-push и не публиковать личные заметки, API-ключи, записи или журналы. Пути разрешённых программ можно настроить под свой ПК; `%LOCALAPPDATA%` раскрывается локально.
